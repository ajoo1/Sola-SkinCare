# SOLA Skincare — دليل الاستخدام السريع

موقع متجر SOLA Skincare — HTML/CSS/JS بسيط، جاهز للرفع على GitHub وربطه بـ Vercel.

## الملفات
```
sola-skincare/
├── index.html      ← هيكل الصفحة
├── style.css       ← كل التصميم (ثيم فاتح/غامق + الألوان البنفسجي/الوردي)
├── script.js       ← كل المنطق (المنتجات، السلة، الشراء، اللغة)
├── assets/
│   └── logo.jpg    ← اللوجو اللي بعتيه
└── README.md
```

## 1) قبل ما ترفعي الموقع — عدّلي البيانات دي

افتحي ملف `script.js` وفي أول سطور فيه هتلاقي:

```js
const CONFIG = {
  whatsappNumber: "201000000000",   // 👈 حطي رقم الواتساب بتاعك هنا (بكود الدولة، من غير + أو صفر إضافي)
  facebook: "https://facebook.com/...",
  instagram: "https://instagram.com/...",
  phone: "+20 100 000 0000",
  email: "hello@solaskincare.com"
};
```

غيّري كل قيمة برقمك/لينكاتك الحقيقية واحفظي الملف.

## 2) إضافة أو تعديل منتج

في نفس ملف `script.js` هتلاقي مصفوفة `PRODUCTS`. كل منتج شكله كده:

```js
{
  id: "cleanser",                 // معرّف فريد بالإنجليزي من غير مسافات
  name: { ar: "اسم المنتج", en: "Product name" },
  desc: { ar: "وصف قصير", en: "Short description" },
  price: 250,
  tag: { ar: "الأكثر مبيعًا", en: "Bestseller" },   // ممكن تسيبيها فاضية ""
  image: "https://placehold.co/500x600/ffe4ee/ad1457?text=Cleanser"
}
```

- عشان تضيفي منتج جديد: انسخي أي عنصر جوه الأقواس `{ }` والصقيه، وغيّري بياناته.
- الصور دلوقتي عبارة عن صور Placeholder مؤقتة — استبدليها بروابط صورك الحقيقية،
  أو حطي صورة المنتج في مجلد `assets/` وسيبي المسار زي `assets/product1.jpg`.

## 3) الرفع على GitHub و Vercel

1. اعملي مستودع (Repository) جديد على GitHub وارفعي كل الملفات دي زي ما هي.
2. من Vercel: **New Project → Import** من نفس المستودع.
3. مفيش أي إعدادات build مطلوبة (الموقع Static HTML) — سيبي كل شيء افتراضي واضغطي **Deploy**.

## 4) طريقة عمل زرار الشراء

- **أضيفي للسلة**: بيحفظ المنتج في السلة (تفتح من أيقونة السلة فوق) ويفضل محفوظ حتى لو قفلتي المتصفح.
- **اشتري دلوقتي**: بيفتح فورم الطلب مباشرة لمنتج واحد بس.
- **إتمام الشراء** (من السلة): بيفتح نفس الفورم لكل منتجات السلة.
- بعد ما الزبونة تكتب اسمها وعنوانها ورقمها وتدوس **تأكيد الطلب عبر واتساب**،
  هيتفتح واتساب برسالة جاهزة فيها بيانات الطلب والفاتورة، وترسلها هي بنفسها.

## 5) اللغة والثيم

- زرار **AR/EN** فوق بيبدّل لغة الموقع كله (منتجات، نصوص، اتجاه الصفحة).
- زرار الشمس/القمر بيبدّل بين الوضع الفاتح والغامق. الافتراضي هو الفاتح.
